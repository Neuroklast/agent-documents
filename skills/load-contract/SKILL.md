# Load contract

Use when scope, risk or overlapping guidance makes the selection non-obvious. Do not create a written contract for a routine edit or pure question.

Record briefly: goal, primary workflow or none, up to two specialists, consequential omissions and exit evidence. Do not turn this into a plan or repeat context already known.

Choose one primary per stage; reference only relevant canonical topics. Add guidance when a new risk or missing decision justifies it; note the reason for expansion. Do not prevent necessary security or verification checks just to meet a numerical limit.

For a long session use [context thread](../context-thread/SKILL.md). For completion see [verification](../verification-before-done/SKILL.md). The [router](../../AGENTS.md) remains the default entry point.
